# DVA-C03 Study Roadmap

## Purpose

This roadmap connects the Stephane Maarek course to practical Python labs and the official AWS Certified Developer – Associate (DVA-C03) exam guide.

The course is a learning resource, not the authority for exam scope. The current AWS exam guide is the source of truth.

## Learning cycle

For each lesson or concept:

1. Capture the lesson title and the relevant exam objective.
2. Explain the concept in plain language, then in accurate AWS terminology.
3. Identify the service responsibility, integrations, limits, and alternatives.
4. Build a small lab when hands-on work adds value.
5. Validate behavior with tests, AWS CLI output, or observable service behavior.
6. Review IAM permissions, data handling, cost, and resource cleanup.
7. Answer scenario-based questions without looking at notes.
8. Record gaps and revisit them using spaced review.

## Study stages

| Stage | Focus | Evidence |
|---|---|---|
| 1 | Cloud fundamentals and AWS global infrastructure | Concept notes and scenario explanations |
| 2 | IAM, credentials, encryption, and application security | Least-privilege policies and secure access labs |
| 3 | Python SDK and AWS service APIs | Small, tested Boto3 integrations |
| 4 | Application services, storage, and databases | Reproducible service-focused labs |
| 5 | Serverless and event-driven application development | Lambda and API integration exercises |
| 6 | Testing, packaging, and deployment | Automated checks and deployment exercises |
| 7 | Logging, monitoring, troubleshooting, and optimization | Diagnostic exercises and cost-aware improvements |
| 8 | Exam readiness | Timed practice, error log, and objective-by-objective review |

## Completion criteria

A topic is not complete merely because its video was watched. Mark it complete when you can:

- Explain the purpose and behavior of the service.
- Select it appropriately in a scenario and justify the choice.
- Identify relevant security and operational concerns.
- Complete the associated lab, if one is required.
- Answer fresh practice questions and explain why distractors are wrong.
