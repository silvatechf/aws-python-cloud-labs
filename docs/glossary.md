# AWS and Cloud Development Glossary

A concise glossary for concepts encountered in the course and labs. Add terms only when they are useful for understanding or exam scenarios.

| Term | Meaning |
|---|---|
| AWS Region | A separate geographic area containing multiple Availability Zones. |
| Availability Zone (AZ) | An isolated location within an AWS Region, made up of one or more discrete data centers. |
| IAM | AWS Identity and Access Management; controls identities and permissions for AWS resources. |
| IAM policy | A JSON document that defines permissions. |
| IAM role | An identity with permissions that can be assumed by trusted principals or services to obtain temporary credentials. |
| SDK | Software Development Kit; libraries that let application code interact with a service. |
| Boto3 | The AWS SDK for Python. |
| API | An interface through which software components communicate. |
| Least privilege | Granting only the permissions required to perform a task. |
| Serverless | A cloud execution model where the provider manages the underlying server infrastructure. |
| Event-driven architecture | A design in which components react to events rather than relying only on direct synchronous calls. |
| CI/CD | Continuous Integration and Continuous Delivery or Deployment; automated practices for validating and releasing software. |
| Observability | The ability to understand system behavior using telemetry such as logs, metrics, and traces. |

## Usage

When adding a term, include a short definition and, where useful, a link to the relevant AWS documentation. Distinguish similar concepts rather than treating them as synonyms.
