# IAM Policy Examples

This directory contains small, reviewable policy documents used in the IAM lessons.

## Rules

- Keep examples non-production and clearly scoped.
- Use placeholder account IDs, resource names, and ARNs.
- Explain whether a policy is identity-based, resource-based, a trust policy, or a permissions boundary.
- Validate policy syntax and intent before using it.
- Never attach an example policy to a real identity without reviewing its effective permissions.

The first lesson uses an inline JSON example. Additional policy files will be added as we study policy evaluation, role assumption, and service-specific permissions.
